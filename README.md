# bljohnson.dev

This is the repository for the code for my personal website [bljohnson.dev](https://bljohnson.dev). It was built using the following tools and technologies:

- [LazyVim](https://www.lazyvim.org/) - my preferred IDE
- [Svelte 5 + SvelteKit](https://svelte.dev) - framework for building user interfaces
- [AT Protocol](https://atproto.com/) - open social protocol
- [Sifa](https://sifa.id/) - a professional identity network built on the Atmosphere
